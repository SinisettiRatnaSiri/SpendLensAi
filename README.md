# SpendLens AI 💰

SpendLens AI is an AI-powered personal finance assistant that helps users understand and manage their spending.

## Features

- 💬 Enter expenses using text
- 📷 Upload/capture receipt images
- 🤖 AI-powered receipt and expense analysis
- 📊 Spending summaries and insights
- 📧 Send spending summaries by email

## Technologies

- Python
- Streamlit
- Google Gemini AI
- Gmail SMTP

## How It Works

1. Enter an expense or upload a receipt.
2. SpendLens AI analyzes the information.
3. The AI identifies spending details and patterns.
4. The app provides useful spending insights.
5. Users can send their spending summary to their email.

## Security

API keys and Gmail credentials are stored in Streamlit secrets and are not included in the public repository.
